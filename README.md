# UX-исследования

Сервис для проведения UX-исследований: регистрация, папки и тесты, конструктор из блоков, публичная ссылка для респондентов и сохранение результатов.

## Запуск

Нужен Node.js ≥ 22.13 (используется встроенный `node:sqlite`). Внешних зависимостей нет.

```bash
npm start            # http://localhost:3000
PORT=8080 DATA_DIR=/var/lib/ux npm start
```

База SQLite хранится в `data/ux.db` (или в `$DATA_DIR`).

## Возможности

- Регистрация и вход (пароли — scrypt, сессии — HttpOnly cookie).
- Папки (создать / переименовать / удалить) и тесты (создать, копия, переместить, удалить).
- Конструктор блоков с автосохранением. Доступны базовые блоки: Вопрос, Выбор, Шкала, Матрица, Предпочтение, Сортировка карточек, Пять секунд. Остальные блоки из палитры показаны заблокированными.
- Шеринг: переключатель «Опубликован» и ссылка `/t/<токен>`; предпросмотр без сохранения ответов.
- Респондент проходит тест без регистрации; ответы сохраняются по ходу прохождения.
- Результаты: сводка по каждому блоку, список прохождений, экспорт в CSV.
